## Systems

<div class="grid cards" markdown>

- **[PyCrypt](https://robcox2910.github.io/pycrypt/)**

    Cryptography. [Source](https://github.com/robcox2910/pycrypt)

- **[PyNet](https://robcox2910.github.io/pynet/)**

    Computer networking. [Source](https://github.com/robcox2910/pynet)

- **[PyWeb](https://robcox2910.github.io/pyweb/)**

    HTTP web servers. Builds on PyNet, PyCrypt. [Source](https://github.com/robcox2910/pyweb)

- **[PyGit](https://robcox2910.github.io/pygit/)**

    Version control. [Source](https://github.com/robcox2910/pygit)

- **[PySearch](https://robcox2910.github.io/pysearch/)**

    Search engines. [Source](https://github.com/robcox2910/pysearch)

- **[PyMQ](https://robcox2910.github.io/pymq/)**

    Message queues. Builds on PyNet. [Source](https://github.com/robcox2910/pymq)

- **[PyLLM](https://robcox2910.github.io/pyllm/)**

    Language models (the brain). Builds on Pebble. [Source](https://github.com/robcox2910/pyllm)

</div>
